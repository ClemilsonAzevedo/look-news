Vale substituir por uma captura de tela real do app rodando — coloque em `assets/screenshot.png` e referencie aqui.## Rodando localmenteVocê vai precisar de [Node.js + npm](https://nodejs.org/en/download) instalados — confira a versão recomendada em `package.json`.### 1. Instale as dependências```bashnpm install```Baixa tudo que o Electron e as bibliotecas do projeto precisam. Pode levar um minuto na primeira vez.### 2. Rode em modo de desenvolvimento```bashnpm start```Compila e inicia o app. Não espere uma janela abrindo sozinha — como é um app de bandeja, ele aparece só como ícone (veja [acima](#onde-encontrar-o-app)); a janela surge ao clicar nele.Por padrão, o app consome a [API já hospedada em produção](../api/README.md#ambientes) — você não precisa da API rodando localmente só para testar o front.## ConfiguraçãoVariáveis de ambiente opcionais — crie um `.env` nesta pasta pra sobrescrever os padrões:| Variável | Padrão | O que faz ||---|---|---|| `LOOK_NEWS_BACKEND_URL` | `https://look-news-api.onrender.com` | URL da API a consumir || `LOOK_NEWS_CRITERION` | `Ciência, tecnologia, startups e investimentos` | Critério de relevância enviado à API || `LOOK_NEWS_POLL_INTERVAL_MS` | `300000` (5 min) | Intervalo do polling em segundo plano |Exemplo pra apontar pro backend local em vez do hospedado:```bashLOOK_NEWS_BACKEND_URL=http://localhost:8080```## Gerando o executávelPra empacotar o app num instalador nativo pra sua plataforma:```bashnpm run make```O [Electron Forge](https://www.electronforge.io/) compila e empacota o app em `out/make/`.> O comando gera só o instalador da plataforma onde ele roda — mac → `.dmg`, Windows → `.exe`, Linux → `.deb`/`.rpm`. Não há cross-compilação automática: pra gerar o `.exe`, por exemplo, é preciso rodar numa máquina Windows de verdade.Pra garantir que compila do zero (útil depois de trocar algo como o ícone):```bashrm -rf outnpm run make```
