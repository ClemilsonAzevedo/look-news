Roda em segundo plano e mostra as notícias ao clicar no ícone.</p>## Onde encontrar o appO Look News não abre como uma janela comum. Ele aparece só como um ícone na bandeja do sistema.<p align="center">  <img src="assets/tray-diagram.png" alt="Posicionamento na bandeja" width="600" /></p>| Sistema | Onde procurar ||---------|---------------|| macOS | Barra de menu, canto superior direito || Windows | Bandeja do sistema (canto inferior direito). Pode estar escondido atrás da seta `^` || Linux | Área de bandeja do desktop (GNOME, KDE etc.) |## Rodando localmenteRequer [Node.js](https://nodejs.org).```bashnpm installnpm start```O app sobe e aparece como ícone na bandeja. Por padrão ele usa a API de produção, então você não precisa rodar o backend localmente.## ConfiguraçãoCrie um arquivo `.env` nesta pasta se quiser alterar os padrões:| Variável | Padrão | Descrição ||----------|--------|-----------|| `LOOK_NEWS_BACKEND_URL` | `https://look-news-api.onrender.com` | URL da API || `LOOK_NEWS_CRITERION` | `Ciência, tecnologia, startups e investimentos` | Critério de relevância || `LOOK_NEWS_POLL_INTERVAL_MS` | `300000` (5 min) | Intervalo de atualização |Exemplo para usar a API local:```bashLOOK_NEWS_BACKEND_URL=http://localhost:8080```## Gerando o executável```bashnpm run make```O instalador fica em `out/make/`.  O comando gera apenas o pacote da plataforma atual (macOS `.dmg`, Windows `.exe`, Linux `.deb`/`.rpm`).
