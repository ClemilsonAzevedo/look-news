It only appears as an icon in the system tray.<p align="center">  <img src="assets/tray-diagram.png" alt="System tray placement" width="600" /></p>| System  | Where to look                                                            || ------- | ------------------------------------------------------------------------ || macOS   | Menu bar, top-right corner                                               || Windows | System tray (bottom-right corner). It may be hidden behind the `^` arrow || Linux   | Desktop tray area (GNOME, KDE, etc.)                                     |## Running locallyRequires [Node.js](https://nodejs.org).```bashnpm installnpm start```The app starts and appears as an icon in the system tray. By default, it uses the production API, so you do not need to run the backend locally.## ConfigurationCreate a `.env` file in this folder if you want to change the defaults:| Variable                     | Default                                         | Description         || ---------------------------- | ----------------------------------------------- | ------------------- || `LOOK_NEWS_BACKEND_URL`      | `https://look-news-api.onrender.com`            | API URL             || `LOOK_NEWS_CRITERION`        | `Science, technology, startups and investments` | Relevance criterion || `LOOK_NEWS_POLL_INTERVAL_MS` | `300000` (5 min)                                | Refresh interval    |Example for using the local API:```bashLOOK_NEWS_BACKEND_URL=http://localhost:8080```## Generating the executable```bashnpm run make```The installer is placed in `out/make/`.The command only generates the package for the current platform (macOS `.dmg`, Windows `.exe`, Linux `.deb`/`.rpm`).
