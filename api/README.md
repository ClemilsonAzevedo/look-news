No Windows use WSL ou Git Bash || Conta Groq + chave de API | [console.groq.com/keys](https://console.groq.com/keys) |### Passos```bashmake download```Crie um `.env`:```bashGROQ_API_KEY=sua-chave-aqui```Suba o servidor:```bashmake run```A API fica disponível em `http://localhost:8080`.## Como usarA rota principal é `GET /news`.Você envia um critério de relevância e uma ou mais URLs de feed. A API busca as fontes, filtra com IA e devolve os artigos em JSON.Documentação interativa (Swagger):| Ambiente | URL ||----------|-----|| Local | http://localhost:8080/swagger || Produção | https://look-news-api.onrender.com/swagger |### Parâmetros| Parâmetro | Tipo | Obrigatório | Descrição ||-----------|------|-------------|-----------|| `criterion` | string | sim | Critério de relevância || `sources` | string[] | sim | URLs dos feeds (`?sources=A&sources=B`) |### Resposta de sucesso (`200`)```json{  "articles": [    {      "title": "string",      "summary": "string",      "link": "string",      "date": "2026-08-20T12:00:00Z",      "source": "string",      "author": "string",      "published": "string",      "terms": ["string"]    }  ],  "total": 0}```### Status possíveis| Status | Motivo ||--------|--------|| `304` | Nada mudou (`If-None-Match`) || `400` | Faltou o parâmetro `sources` || `429` | Limite de requisições excedido || `503` | Todas as fontes falharam e não há cache |A API usa cache HTTP com `ETag` e `Cache-Control: max-age=60, stale-while-revalidate=300`.## ExemplosUma fonte:```bashcurl "http://localhost:8080/news?criterion=tecnologia&sources=https://exemplo.com/feed.xml"```Várias fontes:```bashcurl "http://localhost:8080/news?criterion=ciência+e+tecnologia&sources=https://exemplo.com/feed.xml&sources=https://outro.com/rss"```Requisição condicional:```bash# primeira chamadacurl -i "http://localhost:8080/news?criterion=tecnologia&sources=https://exemplo.com/feed.xml"# chamada seguinte com o ETagcurl -i "http://localhost:8080/news?criterion=tecnologia&sources=https://exemplo.com/feed.xml" \  -H 'If-None-Match: "a1b2c3..."'```## Ambientes| Ambiente | URL ||----------|-----|| Local | http://localhost:8080 || Produção | https://look-news-api.onrender.com |> Em produção (plano gratuito do Render) o serviço pode “dormir” após inatividade. A primeira requisição depois disso demora um pouco mais.
