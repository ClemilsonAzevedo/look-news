On Windows, use WSL or Git Bash || Groq account + API key | [console.groq.com/keys](https://console.groq.com/keys)                       |### Steps```bashmake download```Create a `.env`:```bashGROQ_API_KEY=your-key-here```Start the server:```bashmake run```The API is available at `http://localhost:8080`.## How to useThe main route is `GET /news`.You provide a relevance criterion and one or more feed URLs. The API fetches the sources, filters them with AI, and returns the articles as JSON.Interactive documentation (Swagger):| Environment | URL                                        || ----------- | ------------------------------------------ || Local       | http://localhost:8080/swagger              || Production  | https://look-news-api.onrender.com/swagger |### Parameters| Parameter   | Type     | Required | Description                        || ----------- | -------- | -------- | ---------------------------------- || `criterion` | string   | yes      | Relevance criterion                || `sources`   | string[] | yes      | Feed URLs (`?sources=A&sources=B`) |### Successful response (`200`)```json{  "articles": [    {      "title": "string",      "summary": "string",      "link": "string",      "date": "2026-08-20T12:00:00Z",      "source": "string",      "author": "string",      "published": "string",      "terms": ["string"]    }  ],  "total": 0}```### Possible statuses| Status | Reason                                   || ------ | ---------------------------------------- || `304`  | Nothing changed (`If-None-Match`)        || `400`  | The `sources` parameter is missing       || `429`  | Request rate limit exceeded              || `503`  | All sources failed and there is no cache |The API uses HTTP caching with `ETag` and `Cache-Control: max-age=60, stale-while-revalidate=300`.## ExamplesOne source:```bashcurl "http://localhost:8080/news?criterion=technology&sources=https://example.com/feed.xml"```Multiple sources:```bashcurl "http://localhost:8080/news?criterion=science+and+technology&sources=https://example.com/feed.xml&sources=https://other.com/rss"```Conditional request:```bash# first callcurl -i "http://localhost:8080/news?criterion=technology&sources=https://example.com/feed.xml"# next call with the ETagcurl -i "http://localhost:8080/news?criterion=technology&sources=https://example.com/feed.xml" \  -H 'If-None-Match: "a1b2c3..."'```## Environments| Environment | URL                                ||
